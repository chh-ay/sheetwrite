Format Cells previews the new format on the selected cells while it is open. As you change the number format, alignment, font, border or fill, the selection shows the result at once: negative numbers, zeros, `####` in a narrow column and borders show on every selected cell, where Excel shows only the dialog's one sample. The preview changes only what the grid draws; nothing reaches the document, the undo history or collaborators before OK, and Cancel or Escape puts the cells back as they were.
