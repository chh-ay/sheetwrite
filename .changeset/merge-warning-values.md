The merge warning names the values a merge would discard and their cells. After Excel's text it lists them in reading order, as the cells show them: "These values will be discarded: C2: 'Avery', B3: 'South', C3: 12." It lists the first five and counts the rest ("and 7 more"). Excel's warning does not say which values or how many, so a user could lose values in cells out of view. The buttons and keys are unchanged: Enter is OK, Escape is Cancel, and OK keeps the upper-left value.
