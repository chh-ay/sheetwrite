The ribbon's Number Format box names the format as Excel does. After Ctrl+Shift+$, %, !, # or @, and after the Percent Style and Comma Style buttons, it shows Currency, Percentage, Number, Date or Time instead of Custom: a code that is not a preset shows the Format Cells category that makes it, and only a code no category makes shows Custom.
