description: Release notes for each Sheetwrite version, with new features, changes, fixes, performance results, and upgrade steps.
---

All Sheetwrite packages release together with one version number. Each release
post lists what is new, what changed, what is fixed, the measured performance
results, and the steps to upgrade.

| Version | Highlights |
| --- | --- |
| [0.5.0](/docs/releases/0.5.0/) | Full formula engine, spill references, large undo, conflict recovery without a reload, string memory that stops growing, faster loading and import. |

Releases before 0.5.0 are listed in each package's `CHANGELOG.md` in the
[repository](https://github.com/chh-ay/sheetwrite).
